# 雅思词汇情境阅读生成器设计

## 目标与安全边界

构建一个长期运行、逐章处理、可中断恢复的 Python CLI。原始小说只读；首次正式运行最多处理一章，只有显式写入批量确认后才能扩大范围。API 密钥仅从环境变量或被 Git 忽略的本地 `.env` 读取，日志与异常统一脱敏。

## 架构

系统分为六层：输入解析、全局词汇调度、模型提供者、章节转换与质量门禁、状态存储、导出。模块之间只交换 Pydantic 数据模型。SQLite 是权威运行状态，`progress.json`、`glossary.json`、`glossary.xlsx` 是可移植快照。

### 输入解析

TXT 按 BOM、UTF-8、GB18030 顺序探测；DOCX 读取非空段落；无加密 EPUB 按 spine 顺序抽取 XHTML。章节标题识别覆盖中文数字、阿拉伯数字、Chapter、卷、番外、序章、终章。解析器输出标题、编号、原始自然段和源文件指纹。若没有可靠边界、正文前导占比异常或章节数与文本长度不协调，则只写 `reports/chapter_detection.json` 并停止。

### 全局词汇与复现

全局词条包含 lemma、展示形式、词性、语境释义、音标、CEFR、IELTS 类别、搭配、首次/末次章节、次数、复习计划和原创例句。选择器按章节阶段产生 `target_vocabulary` 与 `review_vocabulary`，执行 60/40、40/60、20/80 比例，并按 20% B1、60% B2、20% C1 与指定词类目标进行加权。首次和第二次出现正文带释义，第三次只在章末词表解释，第四次以后正文仅保留英文。无法自然匹配时允许少于计划复现次数，但质量门禁仍执行密度范围。

完整 5000–7000 词库采用可导入数据文件加严格校验；仓库自带小型测试种子，仅用于接口和样章。未提供或生成经确认的完整词库时，批量确认命令拒绝启用。

### DeepSeek Provider

`ModelProvider` 定义 `generate_chapter()`、`retry_chapter()`、`health_check()`、`estimate_tokens()`。DeepSeek 实现使用 OpenAI Python SDK、`https://api.deepseek.com`、默认 `deepseek-flash`、升级 `deepseek-v4-pro`。请求和系统提示都明确要求 JSON，并给出完整输入输出示例。响应必须非空、未截断且通过 Pydantic 校验。

网络、429 和 5xx 使用带抖动的指数退避；401、402/余额错误立即停止。普通质量失败由 Flash 重试一次，再升级 Pro；每章总重试受 `MAX_RETRIES` 限制。原始响应和脱敏请求元数据分开保存，成功章节使用临时文件加原子替换，绝不覆盖已有成功结果。

### 章节处理与质量门禁

每章拆成稳定的 `chapter-paragraph` ID。超长章按自然段切块，请求后按 ID 合并。硬校验包括 JSON、章节 ID、段落集合、重复/遗漏、长度异常、专名变化、密度、标注格式、Markdown/解释废话、截断和大段重复。失败结果进入 `failed/` 并继续；连续五章失败终止批次。

完整性检查不依赖简单字符串相等，而使用：段落一一对应、数字与专名集合、中文骨架相似度、长度比、重复指纹和末尾锚点。无法可靠判定的语义变化标为人工复核，而不是伪装成自动通过。

### 导出与阅读体验

每章成功后立即生成 DOCX 和 HTML。DOCX 使用一级标题、易读中文字体、英文加粗、英文与释义浅粉背景、统一段距、章末核心词汇表和分页。每 50 章生成带目录域的 Word 分卷。HTML 将词汇包装为可点击元素，展示音标、词性、释义、搭配和累计次数，并提供释义显隐开关。XLSX 汇总全局词库并冻结表头、筛选和设置可读列宽。

### 运行限制与成本

CLI 支持 `--start/--end`、`--chapter`、`--resume`、`--retry-failed`、`--dry-run`。dry-run 只统计字符、Token、请求、章节数和时间。默认 `CONCURRENCY=3`，但 SQLite 写入单点串行化。超过 `MAX_CHAPTERS_PER_RUN` 或 `MAX_ESTIMATED_TOKENS_PER_RUN` 时停止。首次批量确认前，任何非 dry-run 都限制为一章。

### 测试与样章

所有 API 测试使用伪造 OpenAI 客户端，覆盖缺失/无效密钥、429、5xx、超时、坏 JSON、空响应、段落遗漏/重复、专名改变、密度上下界、恢复、跳过成功章、Flash 升级 Pro 和日志脱敏。随后执行脱敏 health check、自建短篇接口验证，并仅处理真实小说第一章。报告字符数、Token、请求次数、耗时、密度、CEFR 分布和每项质量检查。
